    导入 TikZ / CircuitikZ

    粘贴 CircuiTikZ 环境或 TikZ 图片中的代码。支持带 to[...] 的元件、导线（--、-|、|-）、弧线与弯曲、命名坐标（\coordinate 及 (A) 引用）、节点符号、标注、电压、电流、端子与箭头。 支持函数曲线、贝塞尔控制点、数值循环、计算宏及命名样式。建议每次导入一幅图，并检查导入提示。

      关于 CircuiTikZ-Designer v0.0.0

      CircuiTikZ-Designer 是 Circuit2TikZ 项目的一部分。该项目最初是 Friedrich-Alexander-Universität Erlangen-Nürnberg 电子工程研究所的研究项目， 目标是提供一个用于快速、便捷绘制电路并生成 CircuiTikZ 代码的图形界面。

      如果你发现错误或有改进建议，欢迎通过 Github 联系我们。

      标签页管理

      CircuiTikZ Designer 可以为每个浏览器标签页管理独立画布，从而同时绘制多张电路图。

      帮助

      常规

      • 建议定期将电路保存为 JSON 文件。本项目仍处于 alpha 阶段！
      • 每个新的浏览器标签页都是一个独立画布，可同时绘制。你可以在设置菜单中管理这些标签页。
      • 关闭或刷新标签页 不会 清除已绘制的电路；重新打开标签页会重新载入电路。
      • 关闭或刷新标签页 会 清除编辑历史（撤销与重做记录将丢失）。
      • 如果遇到错误，重新载入标签页有时可以解决问题。
